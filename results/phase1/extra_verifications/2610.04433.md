# Verification at source: arXiv 2610.04433 "What Does a Harness Buy? Tokens, Mostly" (Liu, Han; Shandong University)

Read in full on 2026-10-11 (abstract page, full HTML including twelve appendices, code repo YangzeLiu/what-does-a-harness-buy). v1 only, submitted 2026-10-03; no venue.

- Compares agent scaffolds (Claude Code, mini-SWE-agent, OpenCode, DeepSeek CLI) with the same model on SWE-bench Verified (492 tasks; hard45 and pool447 splits) plus a 53-task Terminal-Bench 2.1 check. Harbor 0.22.0 is the run orchestrator and scorer only. The original SWE-bench harness is never run; no port-vs-original comparison.
- Keyword sweep: "parity" 0 hits; "overlap" 0 hits; "adapter" refers to scaffold wiring, not Harbor adapters.
- Statistics (Sec. 3, analysis/paper_numbers.py): paired exact McNemar with Newcombe intervals; TOST at delta = 5 points, passing when the 90% interval sits inside +-5 (pool447 only); Holm correction over six comparisons; smallest gap detectable at 80% power computed from observed discordance (unconditional exact power), plotted against task count (one run per side); rerun flip rate (13-16% of tasks) as the noise yardstick; a split-replication test (do run-1 task splits repeat in run 2; p = .77); Wilson intervals; first-run-only reporting rule fixed before reading results.
- Leaves open: error rates of the range-overlap rule; port-vs-original fidelity; the parity corpus; runs-per-side design with run-level aggregates; injected-defect detection. Its Sec. 5 recommends "a second run of the same cell" as the cheapest control, which parity experiments already do.
- Verdict: narrows (confidence 0.8). We cannot claim to introduce CI + TOST + MDE reasoning to agent-benchmark comparisons; cite it and locate novelty in the overlap-rule analysis, the k-runs design, the 121-experiment port corpus, and the defect study.
